# New config panel for version 1.7.7 of the package

The package comes with a brand new config panel with which not only you are shown the config (like before) but you can edit it.

You don't need to edit the config file anymore on your machine!

Either take a look at the webadmin then `Applications > Matrix-Discord bridge` and then go to the `Main settings`, or play with the `yunohost app config` command.
